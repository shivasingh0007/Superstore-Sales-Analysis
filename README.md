# 📊 Superstore Retail Sales & Profit Analysis (Python & SQL)

## 📌 Project Overview
This end-to-end Data Analytics project analyzes retail transaction data (~10,000 orders) from a Superstore to uncover sales trends, product profitability, and discount impacts. Using **Python (Pandas)** for data cleaning, **SQL (SQLite)** for business querying, and **Matplotlib/Seaborn** for data visualization, this project translates raw data into actionable business recommendations.

---

## 🛠️ Tech Stack & Tools Used
* **Programming Language:** Python 3
* **Data Manipulation & Cleaning:** Pandas
* **Database & Querying:** SQL (SQLite3)
* **Data Visualization:** Matplotlib, Seaborn
* **Development Environment:** GitHub Codespaces / Jupyter Notebook
